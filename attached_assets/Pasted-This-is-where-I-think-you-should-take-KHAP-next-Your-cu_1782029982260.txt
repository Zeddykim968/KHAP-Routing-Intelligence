Step 1: Upgrade Supabase to Real GIS Database

Most people don't know this.

Supabase is PostgreSQL.

You can enable PostGIS.

In SQL Editor:

create extension if not exists postgis;

Verify:

select postgis_version();

Create facility table:

CREATE TABLE health_facilities (
    id SERIAL PRIMARY KEY,
    facility_name TEXT,
    county TEXT,
    facility_type TEXT,
    latitude DOUBLE PRECISION,
    longitude DOUBLE PRECISION,
    geom GEOGRAPHY(POINT,4326)
);

Populate geometry:

UPDATE health_facilities
SET geom =
ST_SetSRID(
ST_MakePoint(longitude,latitude),
4326
)::geography;

Now PostGIS understands location.

Step 5: Replace Haversine With Real Routing

Current:

Straight Line Distance

Future:

Road Distance

Install:

pip install osmnx
pip install networkx

Example:

import osmnx as ox

graph = ox.graph_from_place(
    "Nairobi, Kenya",
    network_type="drive"
)

Now you have actual roads.

Routing:

route = nx.shortest_path(
    graph,
    origin,
    destination,
    weight="travel_time"
)

This is where KHAP becomes special.
